Unit 6: Web Technology I

1. Fundamentals of the Web & Internet

The Internet is a global network of interconnected computers that communicate using standardized protocol suites. The World Wide Web (WWW) is an information system operating over the internet where documents and web resources are identified by URLs and linked via hyperlinks.

  • Web Server: A high-performance computer that hosts websites and serves web pages to users over the network.
  • Web Browser: Application software used to access and display web pages (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge).
  • URL (Uniform Resource Locator): The unique global address used to access a specific resource on the web (e.g., https://www.example.com).
  • HTTP / HTTPS: Hypertext Transfer Protocol (Secure) used for fetching web pages across client-server connections.
  • Domain Name System (DNS): Converts human-readable domain names into IP addresses.

2. Static vs Dynamic Websites

Feature Static Website Dynamic Website
Content Fixed content that remains identical for every visitor. Content changes dynamically based on user interaction or time.
Technologies Built using basic HTML, CSS, and plain images. Built using HTML, CSS, JavaScript, and databases (PHP, Node.js, Python).
Database Does not utilize a backend database. Uses database systems like MySQL, PostgreSQL, or MongoDB.
Speed & Cost Loads quickly, low production and hosting cost. Requires dedicated hosting servers, higher setup cost.

3. Introduction to HTML (HyperText Markup Language)

HTML is the standard markup language used to design the structural layout of web pages. It consists of a series of elements represented by tags that instruct the browser on how to display content.

Basic HTML Document Skeleton

Every standard HTML document follows a nested structure:

  • !DOCTYPE html: Defines the document type and version (HTML5).
  • html: Root element wrapping all document contents.
  • head: Contains metadata, document title, and links to external styles.
  • body: Contains all visible elements (headings, text, images, links, tables).

4. Key HTML Tags & Elements

A. Structural & Text Formatting Tags

  • Headings: h1 through h6 define headings from highest to lowest importance.
  • Paragraph: p wraps standard block text.
  • Line Break: br inserts a single line break (self-closing tag).
  • Horizontal Rule: hr draws a visual dividing line.
  • Text Styling: b or strong for bold, i or em for italic, and u for underline.

B. Hyperlinks & Images

  • Hyperlink (a): Connects web pages together using the href attribute.
    Example: a href="chapter1.html"Go to Chapter 1a
  • Image (img): Embeds graphic files using src, alt, width, and height attributes.
    Example: img src="logo.png" alt="Logo" width="100"

C. HTML Lists

  • Unordered List (ul): Bulleted list of items using li tags.
  • Ordered List (ol): Numbered or alphabetical list using li tags.

D. HTML Tables

Tables organize structured data using these core elements:

  • table: Outer container element (supports attributes like border, cellpadding, cellspacing).
  • tr: Table row.
  • th: Table header cell (bold and centered by default).
  • td: Standard table data cell.

5. Introduction to Cascading Style Sheets (CSS)

CSS is a stylesheet language used to handle the presentation, design, colors, layouts, and responsive formatting of HTML elements.

Three Ways to Apply CSS

  1. Inline CSS: Applied directly within an individual HTML tag using the style attribute.
  2. Internal CSS: Written inside a style block within the document's head section.
  3. External CSS: Linked as an independent file (.css) using the link tag inside the head section.
