  1.Computer


 computer is an electronic device that accepts data and instructions as input, processes them according to the given instructions,
and produces meaningful information as output. It performs arithmetic and logical operations very quickly and accurately. It can 
store large amounts of data and information for future use.A computer works automatically according to the instructions given by 
the user. It is widely used in education, business, communication,banking, science and many other fields.



 2.Computer Technology


 Computer technology refers to the technology used for designing, developing and operating computers and computer-based systems. 
It includes both hardware and software used to process, store and communicate information. It helps computers perform different 
types of tasks efficiently and accurately. Computer technology has developed rapidly with the advancement of electronic devices.



 3.Computer System
 

    
 A computer system is a combination of hardware, software and other components that work together to perform different tasks. It
 accepts data and instructions from the user through input devices. The data is processed by the processing unit according to 
 the given instructions. The processed result is provided to the user through output devices. It can also store data, programs 
 and information for future use.



 4.Computer Architecture


 Computer architecture refers to the conceptual design and functional structure of a computer system. It describes the main 
components of a computer and the way they are designed to work together. It includes the CPU, memory, input unit, output unit and 
other important components. It explains how instructions and data are handled by the computer. Thus, computer architecture represents
 the basic design and functioning of a computer system.



 5.Computer Organization


 Computer organization refers to the physical arrangement and interconnection of different components of a computer system. It
 explains how hardware components such as the CPU, memory and input/output devices are connected. It describes how these components
 work together to perform computer operations. It deals mainly with the implementation of computer architecture. Therefore, computer
   organization describes the actual working arrangement of computer hardware.



 6.Input Unit


 The input unit is a part of a computer system that accepts data and instructions from the user. It receives information through 
different input devices such as keyboard, mouse and scanner. It converts the received data into a form that can be understood by
 the computer. The converted data is then sent to the processing unit for further processing. Thus, the input unit provides a means 
of communication between the user and the computer.



 7.Output Unit


 The output unit is a part of a computer system that provides the processed results to the user. It receives information from the
     processing unit after the data has been processed. It converts the processed information into a form that can be easily understood 
     by the user. Monitor, printer and speaker are common examples of output devices. Therefore, the output unit acts as a communication 
     medium between the computer and the user.



 8.Processing Unit


 The processing unit is the part of a computer that performs operations on the input data. It follows the instructions provided by the
     user or computer program. It performs arithmetic, logical and other processing operations on the data. The Central Processing Unit (CPU)
      is mainly responsible for these processing functions. After processing, the resulting information is sent to the output unit or stored
       in memory.



 9.Memory Unit


 The memory unit is the part of a computer system used to store data, instructions and processed results. It stores data before and during
     processing and also keeps the results after processing. Memory allows the CPU to access the required data and instructions when needed.
      It is broadly divided into primary memory and secondary memory. RAM, ROM, cache memory and storage devices are examples associated 
      with computer memory.

   
 
  10. CPU


 The CPU stands for Central Processing Unit and is the main processing unit of a computer system. It is often called the brain of the 
    computer because it controls and performs most computer operations. It processes data according to the instructions given by a program.
     It performs arithmetic, logical and control operations. The main parts of CPU are the Arithmetic Logic Unit, Control Unit and registers.
    



 11. Microprocessor


 A microprocessor is an electronic integrated circuit that contains the functions of a central processing unit. It performs arithmetic,
     logical and control operations according to the instructions given to it. It receives data, processes it and produces the required 
     results. A microprocessor is commonly used as the main processor in computers and other electronic devices. It allows a computer to 
     perform different processing tasks.



 12. Clock Speed


 Clock speed is the rate at which the processor performs its basic operations. It indicates the number of clock cycles that a processor 
    can complete in one second. It is generally measured in Hertz, megahertz or gigahertz. A higher clock speed usually means that the 
    processor can perform operations faster. Therefore, clock speed is an important factor in determining processor performance.



 13. Word Length


 Word length is the number of bits that a processor can process at a time. It is an important characteristic of a computer processor. 
    Common word lengths include 8-bit, 16-bit, 32-bit and 64-bit. A processor with a larger word length can handle more data in a single 
    operation. Therefore, word length affects the processing capability of a computer.



 14. Bus


 A bus is a set of communication lines used to transfer data, addresses and control signals between different components of a computer. 
    It provides a communication path between the CPU, memory and input/output devices. Buses help different components communicate and
     exchange information. There are mainly three types of buses: data bus, address bus and control bus. The bus system is an important
      part of computer organization.



 15. Data Bus


 A data bus is a group of wires or communication lines used to transfer data between different components of a computer. It transfers data
     between the CPU, memory and input/output devices. Data can generally travel in both directions through the data bus. The width of the 
     data bus determines how many bits can be transferred at a time. A wider data bus can transfer more data in a single operation.



 16. Address Bus


 An address bus is a group of communication lines used to carry the address of a memory location or input/output device. It helps the CPU 
    identify the exact location from which data is to be read or where data is to be stored. The address bus generally carries signals from 
    the CPU to other components. Its width determines the maximum amount of memory that can be addressed. It plays an important role in
     accessing data from memory.



 17. Control Bus


 A control bus is a group of communication lines used to carry control signals between different components of a computer. It helps the 
    CPU control and coordinate the activities of memory and input/output devices. It carries signals such as read, write and timing signals.
     These signals tell different components what operation they should perform. Thus, the control bus helps coordinate the overall operation
      of a computer system.



 18. Primary Memory


 Primary memory is the main memory of a computer that can be directly accessed by the CPU. It stores data, instructions and information
     that are currently being used or processed. It provides faster access to data than secondary storage. Primary memory is generally 
     smaller in capacity than secondary memory. RAM and ROM are the major types of primary memory.



 19. RAM


 RAM stands for Random Access Memory and is a type of primary memory. It temporarily stores data, programs and instructions that are currently
     being used by the CPU. RAM allows the CPU to access stored information quickly and directly. It is generally volatile, meaning its 
     contents are lost when the power is switched off. A computer with more RAM can generally run more programs and handle more data at the
      same time.



 20. ROM


 ROM stands for Read Only Memory and is a type of primary memory. It stores important instructions and programs required for starting and
     operating a computer. ROM is non-volatile, so the information stored in it remains even when the power is switched off. The data stored
      in ROM is normally not changed frequently. It is mainly used to store permanent or semi-permanent instructions.



 21. Cache Memory


 Cache memory is a small and high-speed memory located close to or inside the CPU. It stores frequently used data and instructions so that
     the CPU can access them quickly. It is faster than the main memory but has a smaller storage capacity. Cache memory reduces the time 
     required by the CPU to access frequently needed information. Therefore, it helps improve the overall processing speed of a computer.



 22. Buffer


 A buffer is a temporary storage area used to hold data while it is being transferred from one device or process to another. It is especially
     useful when two devices operate at different speeds. The buffer temporarily stores data until the receiving device is ready to process 
     it. It helps prevent loss of data during transfer. Buffers are commonly used in input and output operations.



 23. Secondary Memory


 Secondary memory is used to store data, programs and information permanently for future use. It is generally non-volatile, so the stored 
    information remains even when the computer is switched off. It has a much larger storage capacity than primary memory. Secondary memory
     is slower than primary memory but is useful for long-term storage. Hard disks, SSDs, optical disks and flash drives are examples of 
     secondary memory.
