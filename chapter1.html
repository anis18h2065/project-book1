Unit 1: Computer System

1. Introduction to Computer System

1. Introduction & Concept of IPOS

A computer system is an electronic device that takes raw data as input, processes it, stores it, and produces meaningful information as output. A computer is an electronic machine that accepts raw data as input, processes it, produces meaningful information as output, and stores it for future reference.

The working of a computer system relies on the IPOS Cycle: The working mechanism is based on the IPOS Cycle:

  • Input: Entering data into the computer.
  • Processing: Performing operations on the data.
  • Output: Displaying the final result.
  • Storage: Saving data for future use.
  • Input: Entering raw data using input devices (e.g., Keyboard, Mouse).
  • Processing: Manipulating data into useful information using the CPU.
  • Output: Displaying processed results using output devices (e.g., Monitor, Printer).
  • Storage: Saving data permanently in secondary memory (e.g., Hard Disk, SSD).

2. Evolution of Computers & Key Milestones

The history of computing evolved through important mechanical and electronic inventions:

  • Speed: Computers can perform millions of calculations per second.
  • Accuracy: They deliver 100% correct results if the input data is correct (GIGO - Garbage In, Garbage Out).
  • Diligence: A computer never gets tired or lacks concentration.
  • Versatility: It can perform completely different tasks at the same time.
  • Storage Capacity: Large amounts of data can be stored securely.
  • Abacus: First counting device invented in China for basic arithmetic.
  • Napier's Bones: Invented by John Napier using bone rods for multiplication and division.
  • Pascaline: Invented by Blaise Pascal; the first mechanical adding machine.
  • Analytical Engine: Designed by Charles Babbage (Father of Computers). It introduced the concept of Input, Process, Output, and Memory.
  • Tabulating Machine: Invented by Herman Hollerith using punched cards.
  • ENIAC: The first general-purpose electronic digital computer.

3. Generations of Computers

Computers are categorized into five generations based on their core technology:

  1. Hardware: The physical parts that you can touch and see.
  2. Software: A set of instructions or programs that guide the hardware.
  3. Data/Information: Data refers to unorganized raw facts, while Information is processed, meaningful data.
  4. Users (Humanware): People who operate and use the system.
  5. First Generation (1940–1956): Used Vacuum Tubes. They were huge, produced immense heat, and used Machine Code. (Example: ENIAC, UNIVAC).
  6. Second Generation (1956–1963): Used Transistors. Smaller, faster, and used Assembly Language. (Example: IBM 1401).
  7. Third Generation (1964–1971): Used Integrated Circuits (ICs). Introduced high-level languages like BASIC. (Example: IBM 360).
  8. Fourth Generation (1971–Present): Uses Microprocessors (VLSI / ULSI). Personal computers (PCs) became widely popular. (Example: Intel PCs).
  9. Fifth Generation (Present & Beyond): Uses Artificial Intelligence (AI) and Quantum Computing for processing voice recognition and problem-solving.

4. Classification of Computers

A. On the Basis of Work / Operation

  • ALU (Arithmetic Logic Unit): Performs mathematical operations like addition (+) and logical decisions like comparison (>, <).
  • CU (Control Unit): Directs and coordinates all activities within the CPU and other components.
  • Registers: High-speed temporary storage units inside the processor.
  • Analog Computers: Measure continuous physical quantities such as temperature, voltage, and pressure (e.g., Speedometer).
  • Digital Computers: Work on discrete binary numbers (0 and 1) for high-accuracy calculations.
  • Hybrid Computers: Combine features of both Analog and Digital systems (e.g., ECG machines in hospitals).

5. Computer Memory System

Memory is used to store data and instructions. It is divided into two main categories:

A. Primary Memory (Main Memory)

Primary memory is directly accessible by the CPU.

B. On the Basis of Size and Power

  • RAM (Random Access Memory): It is volatile memory, meaning data is lost when power turns off.
  • ROM (Read Only Memory): It is non-volatile memory, holding permanent bootup instructions (BIOS).
  • Cache Memory: Ultra-fast memory located between RAM and CPU to speed up processing.
  • Supercomputers: Most powerful and fastest computers used for weather forecasting, scientific research, and defense.
  • Mainframe Computers: Large computers used by banks and government sectors for handling vast databases and heavy traffic.
  • Minicomputers: Medium-sized multi-user computers used in small businesses and universities.
  • Microcomputers: Small, low-cost personal computers used at homes and schools (e.g., Laptops, Desktops, Smartphones).

B. Secondary Memory (Auxiliary Memory)

Secondary memory is used for permanent long-term storage.

5. Characteristics of Computers

  • Magnetic Storage: Hard Disk Drives (HDD).
  • Solid State Storage: SSDs and Flash Drives.
  • Optical Storage: CD, DVD, and Blu-ray Discs.
  • Speed: Performs millions of instructions per second (measured in GHz).
  • Accuracy: Gives 100% accurate results. Errors occur only due to human input mistakes (GIGO - Garbage In, Garbage Out).
  • Diligence: Works continuously without fatigue, tiredness, or loss of concentration.
  • Versatility: Capable of performing various tasks ranging from playing music to solving complex math.
  • Storage: Capable of storing massive amounts of data permanently.

6. System Bus

6. Hardware Components & Von Neumann Architecture

A bus is a set of parallel wires used to transfer data and signals inside the computer: The Central Processing Unit (CPU) is called the brain of the computer. Its internal architecture consists of:

  • Data Bus: Transfers actual data (Bi-directional).
  • Address Bus: Carries memory address locations (Uni-directional).
  • Control Bus: Carries control signals from the Control Unit (CU).
  • ALU (Arithmetic Logic Unit): Handles mathematical operations (+, -, *, /) and logical comparisons (>, <, =).
  • CU (Control Unit): Acts as the central supervisor that directs and manages signal flow between components.
  • Registers: High-speed temporary memory inside the CPU used during data processing.

7. Input & Output (I/O) Devices

Input Devices: Convert human-readable data into machine code (e.g., Keyboard, Mouse, Scanner, OCR, OMR, MICR, Barcode Reader).

Output Devices: Convert machine processing into human-readable format (e.g., Monitors, Printers, Plotters, Speakers).

8. Computer Memory Hierarchy

Memory is classified based on accessibility, speed, and storage capacity:

A. Primary Memory

  • RAM (Random Access Memory): Main working memory. It is volatile (loses data when power cuts off).
  • ROM (Read Only Memory): Contains permanent bootup instructions (BIOS). It is non-volatile.
  • Cache Memory: Extremely high-speed memory placed between the CPU and RAM to speed up access times.

B. Secondary Memory

  • Magnetic Storage: Hard Disk Drive (HDD).
  • Solid State Storage: Solid State Drive (SSD), Pen Drive, SD Cards.
  • Optical Storage: CD-ROM, DVD-ROM, Blu-Ray Disc.

9. System Bus & Microprocessors

A Bus is a path made of signal wires that transfers data, memory addresses, and commands between components:

  • Data Bus: Moves actual data (Bi-directional).
  • Address Bus: Carries memory location addresses (Uni-directional).
  • Control Bus: Carries command control signals from the Control Unit (CU).

A Microprocessor is a single IC chip containing the CPU components (ALU, CU, Registers). Its speed is measured in clock rate (Megahertz or Gigahertz).
