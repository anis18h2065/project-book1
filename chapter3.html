Unit 3: Computer Software and Operating System

1. Concept of Computer Software

Computer Software is a collection of programs, procedures, and documentation that performs specific tasks on a computer system. Software controls hardware operations and transforms raw hardware into a functional computing environment.

2. Classification of Software

Computer software is broadly divided into three main categories:

A. System Software

Software designed to manage system resources, provide a platform for running application software, and directly interface with hardware components.

  • Operating System (OS): Manages hardware, files, processes, and user interface (e.g., Windows, Linux, macOS).
  • Device Drivers: Translates communication between OS and specific hardware peripherals (e.g., Printer Driver, Graphics Driver).
  • Language Translators: Converts source code into machine code (e.g., Compilers, Interpreters, Assemblers).
  • Utility Programs: Maintenance software used to optimize performance (e.g., Antivirus, Disk Defragmenter, Compression tools).

B. Application Software

Programs designed to help end-users perform specific tasks or complete projects.

  • General Purpose Application Software: Packaged software designed for standard everyday tasks (e.g., MS Word, MS Excel, Photoshop).
  • Tailored / Customized Software: Built specifically for a particular organization or business requirement (e.g., School Billing System, Hotel Management System).

3. Operating System (OS) Fundamentals

An Operating System acts as an intermediate bridge between the computer user and the hardware components.

Functions of an Operating System

  • Processor / Process Management: Allocates CPU time to active processes using scheduling algorithms.
  • Memory Management: Tracks main memory (RAM) allocation and deallocation to running programs.
  • File Management: Handles folder creation, deletion, security permissions, and file storage organizational structures.
  • Device / I/O Management: Controls input and output devices using dedicated driver programs.
  • User Interface Management: Provides an interface for human interaction with system commands.

4. Types of Operating Systems

Type Description Example
Single-User OS Allows only one user to access the computer at a time. MS-DOS
Multi-User OS Allows multiple users to access system resources simultaneously. Linux, UNIX
Multitasking OS Executes multiple tasks/programs concurrently. Windows 10/11, macOS
Real-Time OS (RTOS) Processes inputs instantly within strict strict time constraints. VxWorks, RTLinux

5. User Interfaces (CLI vs GUI)

Operating systems offer two major types of user interfaces:

  • Command Line Interface (CLI): Users interact with the OS by typing text commands into a prompt.
    Features: Fast execution, requires low hardware memory, hard for beginners. (e.g., MS-DOS, Linux Terminal).
  • Graphical User Interface (GUI): Users interact with the OS using visual elements like icons, menus, windows, and pointers.
    Features: User-friendly, highly visual, requires higher RAM and storage capacity. (e.g., Windows, Android).

6. Open Source vs Proprietary Operating Systems

  • Open Source OS: Source code is publicly available, free to modify, and free to distribute (e.g., Linux, Android, Ubuntu).
  • Proprietary OS: Source code is closed, owned by a corporation, and requires paid licensing (e.g., Microsoft Windows, Apple macOS).
