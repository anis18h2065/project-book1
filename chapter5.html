Unit 5: Programming Concepts and Logics

1. Introduction to Computer Programming

A computer program is a set of step-by-step instructions written in a specific programming language that tells the computer how to perform a task. The process of writing, testing, and maintaining these instructions is called programming.

2. Generations of Programming Languages

Programming languages have evolved through several generations:

Generation Type Features & Examples
1st Generation (1GL) Machine Language Written purely in binary (0s and 1s). Directly executed by CPU without translation, but extremely hard for humans to write.
2nd Generation (2GL) Assembly Language Uses short symbolic codes called mnemonics (e.g., ADD, SUB, MOV). Requires an Assembler to translate to binary.
3rd Generation (3GL) High-Level Language Uses English-like statements and mathematical expressions. Machine-independent (e.g., C, C++, Java, BASIC).
4th Generation (4GL) Very High-Level Language Non-procedural languages focused on what to do rather than how to do it (e.g., SQL, MATLAB).
5th Generation (5GL) Artificial Intelligence Languages based on solving problems using constraints and visual interfaces (e.g., Prolog, LISP).

3. Language Translators

Since computers only understand machine code (binary), software called Language Translators converts high-level or assembly programs into binary:

  • Assembler: Translates Assembly language programs into Machine code.
  • Compiler: Translates the entire high-level program into machine code all at once. It generates an executable (.exe) file and reports errors after scanning the whole program (e.g., C Compiler).
  • Interpreter: Translates and executes high-level program code line-by-line. If an error is found, execution stops immediately (e.g., Python Interpreter).

4. Program Control Structures

Control structures define the flow of execution in a program:

  1. Sequence Control: Statements execute one after another in linear order from top to bottom.
  2. Selection / Decision Control: Statements execute based on a logical condition evaluating to true or false (e.g., if-else, switch-case).
  3. Iteration / Looping Control: Repeats a block of code multiple times as long as a condition remains true (e.g., for loop, while loop, do-while loop).

5. Problem-Solving Tools

Before writing actual code, programmers use tools to design the program logic:

A. Algorithm

An algorithm is a finite step-by-step set of well-defined instructions written in plain human language to solve a specific problem.

B. Flowchart

A flowchart is a diagrammatic or visual representation of an algorithm using standard geometrical symbols:

  • Oval: Start / Stop (Terminal)
  • Parallelogram: Input / Output
  • Rectangle: Processing / Calculation
  • Diamond: Decision / Condition
  • Arrows: Flow lines showing execution direction

6. Introduction to C Programming

C is a structured, procedural high-level programming language developed by Dennis Ritchie at AT&T Bell Laboratories in 1972. It forms the base for modern languages like C++, C#, Java, and Python.

Basic Elements of C

  • Keywords: Reserved words with fixed meanings that cannot be used as variable names (e.g., int, float, if, return).
  • Identifiers / Variables: User-defined names given to storage locations in memory.
  • Data Types: Specifies the type of data stored (e.g., int for integers, float for decimals, char for single characters).
